# Secure Cleaning Inspection Worksheet

This folder contains a Secure Cleaning-branded replacement for the original
`Cleaning Works - Quoting Pad.pdf`.

Files:

- `secure-cleaning-site-inspection-worksheet.html`
  - Print-friendly worksheet
  - Best for visual review, browser editing, and future conversion into a web form
- `secure-cleaning-site-inspection-worksheet.rtf`
  - Editable in Microsoft Word, Apple Pages, and most rich-text editors
  - Best for day-to-day office edits and versioning
- `secure-cleaning-wordmark.svg`
  - Lightweight Secure Cleaning header graphic used by the HTML worksheet

Design choices:

- Kept the original one-page field-workflow feel
- Replaced the old branding with Secure Cleaning styling
- Added suburb/postcode, inspector, quote ref, and remote estimate fields
- Added grouped commentary / adjustment sections so manual site notes can be
  transcribed into a future inspection worksheet and firm quote flow
- Kept glass cleaning as a separate noted item rather than folded into the core
  remote estimate

Recommended next step:

Use this worksheet during inspections, then build a matching in-app
`inspection_reports` workflow so agents transpose these notes into structured
digital quote data.
